MD Files Uploader

MD Files Uploader is a private, single-user tool used by the owner of the YouTube channel MD Files to upload short video clips to that channel.

The tool runs only on the owner's own computer. It is not offered to the public and has no user accounts. It uses the YouTube Data API to upload videos and to read basic information about the owner's own channel.
